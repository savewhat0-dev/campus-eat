Replace package.json AND package-lock.json at the WEBSITE repository root with these files. This is the website package, containing build:render and start:render. Do not use the Expo package.json on Render. In Render > Service > Settings, Root Directory must point to the folder containing the website package.json, index.html, render/ and public/; leave it blank when these are at repository root. Build: npm ci --include=dev && npm run build:render. Start: npm run start:render. Keep existing secrets/database. Deploy latest commit. If website source was replaced with the app project, restore the complete website ZIP instead.
